    📖 Hướng dẫn kết nối ChatGPT
    
    
      
      
    1. Bật Developer Mode: chatgpt.com → Settings → Apps & Connectors → Advanced → bật Developer mode.
      2. 
      
    2. Server + Tunnel: với từng workspace (WORKSPACE_PATH + EXTRA_WORKSPACE_PATHS nếu có), bật Focus Server (mục 3) rồi Focus Tunnel (mục 4).
      3. 
      
    3. Tạo connector: Settings → Connectors → Create. Name: Local Coder, URL: URL tunnel (hoặc dán Tunnel ID nếu dùng OpenAI Tunnel), Authentication: None. Mỗi workspace một connector riêng.
      4. 
      
    4. Bắt buộc tag connector: Chat mới → + → More → bật connector, hoặc gõ @TênConnector trong ô chat. Không tag → ChatGPT báo "Lỗi trong luồng tin nhắn" mà server không có log.
      5. 
    
    
    
    
    
    Tip: sau khi restart server → Refresh connector + mở chat mới + tag lại. Không bấm "Luôn cho phép" trên popup — cấu hình quyền ở Settings → Apps.
